Format notes

CSV
  • Headers: ID, Website/App Name, Investment Type, Sub Type Name, Sub Type Category, Amount, Investment Date
  • Date format: YYYY-MM-DD
  • Matching records (platform + type + sub-type + category) are updated
SQL
  • Exports all tables: investments, investment_history, sub_type_names, sub_type_categories, investment_transactions, bank_accounts, bank_transactions, bank_category_rules, bank_budgets
  • Works when backend uses MySQL or MongoDB — Mongo data is converted to MySQL INSERT statements
  • Merge: adds data without clearing existing records (MySQL backend)
  • Fresh install: truncates all tables then imports — like a clean setup (MySQL backend)
MongoDB
  • Extended JSON format with all portfolio collections (including bank_accounts and bank_transactions)
  • Compatible with mongoimport and MongoDB tools
  • Works when backend uses MySQL or MongoDB (DB_TYPE)
  • Merge: upserts by document ID
  • Fresh install: clears all collections before import
